release: v0.4.1 — AMD install polish (real hostname, vendor-aware UI)

First user-visible iteration of the v0.4.0 AMD path after a real
Jarvis Strix Halo install. Three Docker-Container-specific traps
came out of that:

- os.hostname() returned the container ID ("48f38404d5f8") on every
  surface that read it (Hosts table label, System page chip,
  seedLocalIfMissing's hostname column, host card subtitle). Inside
  a container, that's the container's UTS namespace name, not the
  underlying host. The compose files already bind-mount /proc:/host
  /proc:ro for the process collectors; new utility
  server/utils/hostHostname.ts reads /host/proc/sys/kernel/hostname
  from there to recover the real value (e.g. "jarvis"). Bare-metal
  installs without HOST_PROC fall back to os.hostname(). Cached
  after the first call.
- docker-entrypoint.sh hardcoded the nvidia-smi probe, so AMD users
  got a misleading "WARNING: nvidia-smi not found in PATH" at every
  container start even when GPU_VENDOR=amd worked fine. The script
  now mirrors the Node-side resolution: nvidia / amd check their own
  binary; auto probes both and warns only if neither is reachable;
  MOCK_GPU=1 skips the check entirely.
- The hub image shipped without agent/dist/agent.mjs because the
  builder stage never ran npm run build:agent. Every boot logged
  "[WARN] [agent-dist] agent.mjs missing … /install.sh + /agent.mjs
  will 503". The bundle is now built in the builder stage and copied
  into runtime alongside the install.sh template — the curl install
  path for remote agents works out of the box.

UI strings caught up to the AMD reality:
- System page "GPU" section subtitle no longer claims "Accélérateurs
  NVIDIA remontés par nvidia-smi" — both vendors mentioned now.
- "Hub" badge added to the System page Host card title (matches the
  badge in Settings → Hosts) so users see at a glance that THIS box
  is the master, not a remote agent.
- "no_gpu" placeholder mentions rocm-smi as a possibility too and
  points users at GPU_VENDOR + the hub boot logs.
- hosts.section_help + hosts.hub_badge_help mention both smi
  binaries.
- Boot banner subtitle: "Real-time NVIDIA / AMD GPU Dashboard".

Typecheck + build green; behaviour validated end-to-end on a Strix
Halo Mini-PC via docker-compose.amd.yml.
