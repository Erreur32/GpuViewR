release: v0.8.12 security cleanup (deps + Docker base image)

Batch of Dependabot security fixes merged today, bundled into one
release with a Docker-side fix that couldn't come from a PR alone.

Dependency CVE fixes
---------------------
- react-router-dom -> 7.18.2 (5 advisories: CSRF bypass, open
  redirect, arbitrary constructor injection, DoS via inefficient
  route matching, XSS via missing protocol validation)
- ip-address -> 10.5.0 (3 advisories: SSRF/trust-boundary bypasses
  via octal/CIDR/IPv6 address confusion)
- fast-uri -> 3.1.5 (3 advisories: host confusion via
  backslash/IDN authority parsing)
- postcss -> 8.5.25 (path traversal / arbitrary .map file
  disclosure via sourceMappingURL)
- body-parser -> 2.3.0 (DoS via silently disabled size limit)
- brace-expansion (exponential-time DoS)
- esbuild/vite (arbitrary file read on Windows dev server)
- ws -> 8.21.0 in the agent bundle (memory exhaustion DoS via tiny
  WS fragments)

Docker base image
------------------
- node:22-trixie-slim digest bump (e637ac9 -> 8cd0ffd), both
  builder and runtime stages.
- Runtime stage now self-updates npm (npm install -g npm@latest)
  so the vendored pacote moves past 19.0.2, which is vulnerable to
  SNYK-JS-PACOTE-8225084 (CPU-exhaustion DoS via addGitSha), to a
  patched version. The base image tag itself still ships the old
  npm/pacote pair, so this couldn't wait on a future image release.

CI
---
- Bumped 11 GitHub Actions across workflows (ci-minor-patch
  Dependabot group), digest-pinned refresh, no behavior change.

Internal
--------
- 34 Dependabot alerts fixed, 1 auto-dismissed, 0 open PRs.
- Snyk Container pacote alert addressed via the Dockerfile change
  above. Scorecard Vulnerabilities alert will clear on its next
  scheduled scan now that the underlying CVEs are fixed.

Upgrade
-------
- `docker compose pull && docker compose up -d` on the hub host.
- No DB migration.

Workflow note
-------------
- Branch push only. Tag v0.8.12 only after SonarCloud is confirmed
  green, per the project's release rule.
