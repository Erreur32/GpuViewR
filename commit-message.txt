release: v0.9.11 detect kernel threads via /proc/<pid>/status

- Fixed: the 0.9.10 kernel thread check read /proc/<pid>/stat for every
  new pid, which AppArmor audits, so agents kept logging 10 to 20
  ptrace denials per minute. Read the Kthread: line of
  /proc/<pid>/status instead (silent), PPid: 2 fallback on older kernels.
