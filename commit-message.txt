release: v0.1.21 - default chart range to live

Changed:
- Dashboard chart now defaults to "live" on first run instead of
  "1h". Existing users keep their last selected range; only the
  fallback for fresh localStorage changes.
- Removed the dedicated 1m/2m -> live migration introduced in
  v0.1.9 for upgrades from <= 0.1.8. Any unknown stored range
  (including 1m/2m) now falls back to "live", which covers the
  same case with less code.
