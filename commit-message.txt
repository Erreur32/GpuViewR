release: v0.1.30 - real PCIe RX/TX, separate Link bandwidth tile

Fixed:
- The PCIe card's RX and TX tiles displayed the same value (the
  link's theoretical capacity, gen x width in GB/s) instead of
  real instantaneous traffic. Both pointed at the same variable.

Added:
- gpuCollector now spawns `nvidia-smi -q -d PCI` per tick in
  parallel with the CSV query, parses `Tx Throughput` /
  `Rx Throughput` per GPU (matched by Bus Id), and exposes
  pcie_rx_kbps / pcie_tx_kbps on GpuSample. Falls back to null
  when the driver returns N/A (typical on consumer GeForce
  without admin or with older drivers).
- Dashboard: separate RX, TX, Link bandwidth (theoretical max)
  and Link gen/width tiles. RX/TX humanized (KiB/s -> MiB/s ->
  GiB/s); '-' when not available.
- Mock GPU data synthesizes asymmetric, non-trivially-different
  RX and TX waves so the UI demonstrates two distinct values
  without a real card.
