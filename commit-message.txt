release: v0.1.31 - System page Concept B (condensed metadata)

Changed:
- System page Host/CPU/Memory cards now condense their metadata
  into a single dotted line on the title row (Concept B), instead
  of a 3-column label-value grid. The card body is now reserved
  for the bars/gauges, which roughly doubles their relative
  vertical share.
- Per-GPU sub-cards collapse the InfoField grid into two muted
  inline lines: identity (driver, PCIe link) on the right of the
  title, and live readings (temp, power, fan, clocks, bus id,
  truncated UUID) directly underneath. Util/Memory bars sit
  immediately below the metadata — no more 6-cell grid above.
- Memory bar gains a sub-line "X used / Y total" so the removed
  three-field grid stays glanceable.
