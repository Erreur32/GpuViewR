release: v0.10.0 installer GPU detection and install docs

- Fixed: installers now detect AMD GPUs without ROCm (amdgpu card in
  /sys/class/drm; Docker paths also need /dev/kfd).
- Fixed: NVIDIA without the NVIDIA Container Toolkit no longer breaks the
  Docker installs: install.sh starts the hub alone with the fix command
  and clears a stale COMPOSE_PROFILES=nvidia; install-agent.sh stops with
  a clear hint.
- Added: supported hub platforms and compose examples (hub only, NVIDIA,
  AMD) in Docs/INSTALL.md, reorganized README Install section.
- Changed: English-only docs with a Docs/ index, ws 8.22.0, demo gains a
  Windows host.
