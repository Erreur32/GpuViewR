release: v0.1.5, interactive legend + util N/A fix

Live chart
- Util / Temp / Power chips below the chart are clickable again to
  hide / show each series. Hidden series get dimmed opacity and a
  struck-through label. Restores the toggle behavior expected from a
  chart legend (the previous build dropped it when uPlot's built-in
  legend was disabled).
- Two new short ranges 1m and 2m for real-time monitoring (in addition
  to 5m / 15m / 1h / 6h / 24h / 3d). Server parseRange also accepts a
  seconds suffix now.

GPU utilization N/A
- nvidia-smi --query-gpu=utilization.gpu returns [N/A] on a number of
  consumer / container / MIG / vGPU configs. The collector used to coerce
  that to 0, which poisoned the Min / Avg / Max stats card and the live
  gauge with a fake 0% reading.
- Utilization is now nullable end-to-end (GpuSample, GpuMetric row,
  zustand store, LiveChart, gauges). Null renders as N/A on the gauge
  and as a dash on the stats card instead of a misleading 0%.

Memory gauge
- The memory card now shows the used value on the main line (e.g.
  "4 MiB") and "/ 8 192 MiB" on a secondary line, matching the layout
  of the temperature / utilization / power gauges. Driven by a new
  displaySubValue prop on GaugeCard.

Settings > Updates
- The latest version's release notes (from the GitHub release with a
  fallback to local CHANGELOG.md) now show directly in Settings >
  Updates, even when you are already on the latest version. Includes a
  "View on GitHub" link. updateService.runCheck fetches release notes
  unconditionally so the panel can render them.
