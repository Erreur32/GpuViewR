release: v0.10.3 install.sh --upgrade for systemd agents

- Added: install.sh --upgrade refreshes bundle + systemd unit from the
  existing env file, keeps the host identity, no token needed. Brings the
  v0.10.2 unit changes (CAP_SYS_PTRACE + seccomp) to older installs.
- Changed: UI banner, model-name hint and Hosts update button show the
  --upgrade command; the v0.10.2 ptrace.conf drop-in is removed.
