release: v0.9.5 per-host color picker on Settings → Hosts

- Added: a color swatch next to each host's label on Settings → Hosts
  opens a picker (10-color palette, custom color, Auto reset). The
  chosen color now stays pinned to that host everywhere on /fleet
  (legend, chart line, tooltip) instead of shifting with fleet
  composition changes.
- Default palette's 3rd color changed from orange to mauve/fuchsia.
