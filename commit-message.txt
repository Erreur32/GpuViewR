release: v0.1.10 - Custom tab, history cache, About polish, persistent WS

- New "Custom" tab in Settings: theme picker, gauge style (moved from
  General) and a Chart curves card with 5 presets (Cyber, Sunset,
  Aurora, Royal, Graphite) plus per-metric color pickers.
- About tab: real /GPUViewR.png logo, README-style badges, colored
  changelog renderer, expanded by default.
- Updates tab: new "Update banner" card with show/hide toggle.
- gpuStore caches chart history per gpu|range so the live chart
  paints instantly when returning to the Dashboard from another tab.
- useGpuStream lifted to AppLayout so the WebSocket stays open while
  the user is on Settings / Alerts / Logs.
- Sonar S7773: parseInt / parseFloat -> Number.parseInt /
  Number.parseFloat sweep across server and src.
