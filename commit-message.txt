release: v0.9.3 process-list auth fix, encrypted export secrets, AMD multi-card attribution

- Security: /api/processes had no authentication at all, exposing GPU
  process lists across every host with zero auth. Fixed.
- Security: MQTT/InfluxDB/Telegram export secrets are now encrypted at
  rest (AES-256-GCM), with an optional dedicated ENCRYPTION_KEY env
  var decoupled from JWT_SECRET.
- Fixed: multi-card AMD hosts attributed every GPU process to card0.
  Per-process attribution now cross-references the kernel's DRM
  fdinfo interface for correct per-card assignment.
