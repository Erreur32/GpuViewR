release: v0.1.17 - stats reorder + fan, CSV export, exporter info, password reset CLI

- Stats cards & graph now follow the Temp · Util · Memory · Fan ·
  Power order across the gauges above the chart, the Statistics
  table, the chart legend chips and the cursor tooltip. Fan card
  added to the gauge row; per-category colors preserved.
- Footer aggregate pill folds in average fan speed (skipped on GPUs
  that don't expose fan_speed), in the same global order.
- New scripts/reset-password.ts (npm run user:reset-password) for
  admins who lose web-UI access. Honors DATA_DIR, supports --list,
  masked prompt + confirm, or non-interactive --password=<value>.
- New "What's being sent" panel under each enabled exporter
  (Prometheus, MQTT, InfluxDB) showing the active endpoint and the
  exact metrics / topics / payload keys / HA sensors / tag+field
  keys, sourced from a single catalog shared with the publishing
  code so the panel and the actual exposition can't drift.
- Webhook block: custom headers editor for the generic type, and
  the push interval is now visible for every webhook type in
  metrics mode (previously hidden for Discord/Telegram even though
  the server scheduled their pushes).
- Streaming GET /api/gpu/history.csv (gpu=<i>|all) backed by
  SQLite iterate(), with a "CSV" download button next to the chart
  title - UTF-8 BOM for Excel-friendly opening, RFC-4180 escaping.
- New Notifications section in Settings -> General: global sound
  toggle and a one-click "Enable browser notifications" button
  surfacing the current permission state (granted / not asked /
  blocked / not supported).
- Notification icon switched to /GPUViewR.png to match the
  branding used everywhere else.
- selectedGpu now persists across reloads (key: gpuviewr.selected_gpu).
