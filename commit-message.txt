release: v0.1.32 - PCIe RX/TX index fallback, yellow process names

Fixed:
- PCIe RX/TX could stay at "-" when the CSV pci.bus_id (from
  --query-gpu) and the GPU block header (from nvidia-smi -q -d
  PCI) disagreed on format. The throughput parser now stores each
  block under both keys (bus-id + idx:N block order) and the
  merge tries bus-id first, then index. Adds a one-shot
  diagnostic log at startup describing the parsed map so any
  remaining "-" can be debugged without a redeploy.

Changed:
- Per-GPU "Processes using this GPU" table renders process names
  in warm yellow (var(--gv-warn)) so binary paths stand out from
  PID and VRAM columns at a glance.
