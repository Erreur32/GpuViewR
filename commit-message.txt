release: v0.9.14 NVIDIA graphics processes in the process table

- Fixed: graphics-only NVIDIA processes (Xorg, compositors, browsers)
  were never listed, --query-compute-apps skips them. The agent now
  also parses nvidia-smi -q -d PIDS, mapped to the GPU UUID via the
  PCI bus id.
- Fixed: recent drivers print "C+G" instead of "G+C", the process
  type was dropped. Both spellings map to G+C.
