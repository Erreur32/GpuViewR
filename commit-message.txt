release: v0.8.25 collapse dashboard header controls into dropdowns

- Gauge/compact view toggle: icons only, no label text.
- Time-range picker collapsed into a single dropdown button showing
  the active range instead of listing all 7 choices inline.
- Per-GPU tab strip collapsed into a dropdown too, so multi-GPU hosts
  don't push the header wider than the page.
- Both new dropdowns use an opaque background instead of the
  toolbar's semi-transparent one.
- Gauge/compact toggle padding trimmed to align its height with the
  other header controls.
- Dev-only: mock-agent-1 now exposes two synthetic GPUs so the "all
  GPUs" view is testable under MOCK_GPU=1.
