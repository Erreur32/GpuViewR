release: v0.2.5 - installable PWA (standalone Chromium app)

Added:
- Progressive Web App support via vite-plugin-pwa. GpuViewR can be
  installed as a standalone Chromium app from the browser's install
  prompt. A generated service worker precaches the app shell so the
  window opens even when the backend is unreachable; the existing
  useGpuStream reconnect logic then drives the footer "disconnected"
  pastille until /api and /ws come back.
- Live data endpoints (/api/*, /ws/*) are explicitly excluded from
  the service worker's navigation fallback, so metrics are never
  served stale from cache.
- New PWA icons (pwa-192x192.png, pwa-512x512.png, maskable variant)
  generated from gpuviewr.svg, and an apple-touch-icon link in
  index.html for iOS home-screen.

Changed:
- Demo CSP whitelists manifest-src 'self' and worker-src 'self' so
  the service worker registers correctly on GitHub Pages.
