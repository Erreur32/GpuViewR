release: v0.1.12 - webhook overhaul, Notification/Metrics sub-tabs, update check UX

- Webhook now supports Generic (JSON), Discord (embed) and Telegram
  (Bot API) with two modes: 'alerts' (fired on alertService events)
  and 'metrics' (periodic push of latest samples).
- Webhook test actually checks the remote HTTP status and reports
  the body excerpt on failure. Generic webhook protects its
  Content-Type header.
- Settings > Exports tab split into two sub-tabs: Notification
  (webhook) and Metrics (Prometheus, MQTT/HA, InfluxDB).
- Update check (recheck button) always toasts the result: up to
  date / update available / failure.
- Token / chat ID secrets masked in webhook config API responses.
