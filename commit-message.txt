release: v0.1.43 - host stats on all exporters, host alert presets, MQTT polish

Added:
- Host metrics on every exporter, toggleable via includeSystemStats
  (off by default):
  - Prometheus: gpuviewr_host_* gauges on /metrics (CPU usage ratio,
    load 1m / 5m / 15m, memory used bytes/ratio).
  - MQTT: retained JSON on <prefix>/host/state, plus HA discovery
    for the host sensors when haDiscovery is on.
  - InfluxDB: extra point per push on <measurement>_host with
    cpu_usage_pct, load_1m/5m/15m and memory_used_pct.
  - Webhook (already in 0.1.41), now mirrored everywhere.
- Host-scoped alert presets. AlertMetric extended with host_cpu,
  host_load_1m, host_memory. New presets:
    Host CPU critical (>95% / 60s, sound)
    Host CPU high (>85% / 120s)
    Host load high (>4.0 / 120s, tuned for >=4 cores)
    Host RAM saturated (>95% / 30s, sound)
    Host RAM high (>90% / 60s)
- Rule editor: metric <select> split into an <optgroup> "GPU" / "Host"
  for clarity. METRIC_ICON, METRIC_ORDER and i18n cover the three new
  metrics.
- gpuviewr_host appears as its own HA device when MQTT discovery +
  host stats are both on.

Changed:
- MQTT settings layout: broker URL, status, push interval moved out
  of the "What's being sent" disclosure into a flat status block
  above (no more text overlap). Disclosure keeps only payload spec.
- MQTT toggles: "Publier les stats machine" gets its own padded
  block + helper; "Sensors auto-appear in Home Assistant" is now
  glued to the HA discovery toggle instead of floating.
- HA help restyled: numbered colored badges, info-tinted step rows,
  accent-tinted inline labels ('value') and info-tinted placeholders
  (<broker-host>). Em-dashes removed from steps.

Removed em-dashes:
- "Les règles ajoutées sont désactivées — verifiez..." -> ":" form.
- HA help steps 2/4/5 reworded to drop the em-dash.

Internal:
- alertService no longer needs `as unknown as GpuSample`. New
  EvalSample = GpuSample | HostSample union + isHostSample type
  guard, readMetric narrows cleanly.
- buildInfluxHostLine() centralizes the host line-protocol format;
  INFLUX_HOST_FIELD_KEYS drives writer + dispatch panel.
