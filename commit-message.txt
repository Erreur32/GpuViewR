release: v0.1.8 - tabbed settings, chart thresholds, gradient fills, cursor tooltip

UI / Settings
- Settings page now grouped into tabs: General / Exports / Database / Updates.
  Active tab is persisted in localStorage (gpuviewr.settingsTab).
- New "Chart thresholds" card in the General tab: master toggle, per-metric
  value (utilization %, temperature °C, power W), per-field clear button,
  and "Restore defaults" action. Defaults: util=95%, temp=83°C, pow=350W.

Chart
- Dashed reference lines drawn on the live chart for each enabled metric,
  using uPlot's draw hook so the lines respect series visibility, theme,
  and custom colors. Thresholds toggle / values redraw the chart in place.
- Modern area fills: vertical gradient (top ~32% alpha → 0% at bottom)
  applied to utilization, temperature, and power series for a cleaner
  Grafana-style look.
- Hover tooltip following the cursor: shows the sample's date/time
  (24h/12h aware) and the values of currently visible curves with their
  series color dots.
- X-axis time labels now follow the user's 24h / 12h preference and add
  seconds automatically when the tick spacing is below one minute.

Tooling
- scripts/update-version.sh: stop rewriting the static "GpuViewR-vX.Y.Z"
  README badge - the dynamic GitHub Release badge already updates itself,
  so the static one was removed from the README.
