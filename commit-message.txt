release: v0.8.21 Windows log rotation + install cross-mode guard

Three fixes from the open TODO list:

- Windows agent.log had no rotation and grew unbounded under
  C:\ProgramData\GpuViewR-Agent\. The generated launcher.ps1 now
  rotates it past 10 MB (.1/.2/.3, oldest dropped), checked on every
  log write (both the launcher's own Write-Log and node's stdout).
- install.sh (systemd) and install-agent.sh (Docker) now refuse to
  run if the other mode is already installed on the host (Docker
  container gpuviewr-agent / systemd gpuviewr-agent.service) — running
  both at once double-reports the same GPU under two host ids. Both
  accept --force to bypass.
- Delete-host modal warning hardcoded "systemd restart loop" even
  though it shows for all 3 install modes; generalized in fr/en.

Rotate-token modal was audited and found already correct since
v0.8.4 (no change needed).
