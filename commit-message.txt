release: v0.1.15 - better GPU process name detection, license cleanup

- processCollector: when nvidia-smi reports "[Not Found]" (or
  empty / "-" / "N/A") for a compute-app process_name, fall back
  to reading /proc/<pid>/cmdline (basename of argv0) and then
  /proc/<pid>/comm before labeling the row "unknown". Resolves
  rows that used to stay stuck on "[Not Found]" forever.
  Requires the container to share the host PID namespace
  (`pid: host` in docker-compose.yml) for host-side processes.
- LICENSE & README: drop the legacy bigsk1/gpu-monitor copyright
  block from both the LICENSE file and the README license excerpt.
