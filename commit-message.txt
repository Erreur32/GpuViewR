release: v0.9.18 Windows process list enabled and filtered

- Fixed: Windows process list stayed empty after v0.9.17, the installer
  wrote FEATURES='gpu' and auto-update never rewrites agent.env.ps1. The
  installer now defaults to gpu,processes and the agent reads the legacy
  'gpu' value on Windows as gpu,processes.
- Fixed: Windows process list listed every desktop window. Only rows
  with >= 256 MiB dedicated VRAM or GPU activity in the last 30 s are
  kept; the System pseudo-process is hidden.
