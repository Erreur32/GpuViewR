release: v0.8.5 — Windows uninstall command in delete modal + dedup install templates

Added
- Delete-host modal's command-toggle gains a Windows tab. Pasted
  in elevated PowerShell, it downloads install.ps1 from the hub
  and invokes it with -Uninstall — same flow install.ps1's
  bottom-of-output hint suggests after a successful install.
  Default tab follows the host's reported install_mode so a
  Windows agent's deletion modal pre-selects the right command.

Internal — SonarCloud dedup
- Triggered by the 27 % duplicated-lines threshold on
  HostsSettingsTab.tsx after v0.8.4 added the RotateTokenModal's
  3-mode install picker that duplicates EnrollHostModal's. The
  fix extracts the shared bits into a new module
  src/components/settings/_installCommands.tsx:
    - InstallMode union type ('curl' | 'docker' | 'windows')
    - buildInstallCommands(hubHttp, token) → { curl, docker,
      windows }: the three install one-liner templates
    - LABEL_KEY_BY_MODE: i18n key map for the CopyValueBlock
      label
    - defaultModeFor(installMode): "what mode should the picker
      open on?" — falls back to 'curl'
    - <InstallModePicker mode onChange />: the segmented toggle
      JSX itself
- Three modals consume the module:
    - EnrollHostModal (Add host) — switched to
      buildInstallCommands + <InstallModePicker>; dropped its own
      Terminal/Container/Monitor icon imports + cmdByMode +
      labelKeyByMode.
    - RotateTokenModal (Rotate token, added in v0.8.4) — same.
    - DeleteHostModal (this release) — same, plus the new
      Windows uninstall command (3rd mode it didn't have before).

Net effect: ~90 LOC of duplicated template + JSX consolidated
into ~110 LOC of single-source module. Adding a future install
mode is a one-line change in `_installCommands.tsx`.

Files
- src/components/settings/_installCommands.tsx (NEW, ~110 LOC).
- src/components/settings/EnrollHostModal.tsx: refactored to
  import from the shared module.
- src/components/settings/HostsSettingsTab.tsx: RotateTokenModal +
  DeleteHostModal refactored, plus the Windows uninstall command
  added.

Verified: tsc 0 errors, vite build green.

Upgrade
- Hub: docker compose pull && up -d --force-recreate.
- Effect immediate the next time Add / Rotate / Delete modals
  open.
