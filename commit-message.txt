release: v0.8.20 fix agent reconnect loop + real agent enable/disable toggle

Two remote agents (Deb13, Windows Gamer) were stuck bouncing every
~30s in prod: connect, reject after ~600ms with "Rate limit exceeded
(101 frames/s > 100)", reconnect, repeat. Root cause was a collision
between the agent's offline-buffer replay and the hub's rate limit —
chunks of 50 buffered frames were replayed every 600ms, but the hub
counts messages over a 1000ms sliding window, so two consecutive
chunks (plus the hello frame sent right before the drain) landed in
the same window: 101 frames, tripping the close and growing the
backlog on every aborted attempt. Spacing replay chunks 1100ms apart
fixes it for good.

Also swaps the non-functional auto-update toggle that had been added
to the hub's own row (the backend always rejects PATCH on the local
host) for a real enable/disable toggle on remote agent rows: turning
one off force-closes its live socket and rejects its next handshake,
turning it back on lets it reconnect normally.
