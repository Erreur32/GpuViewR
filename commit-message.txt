release: v0.1.2

This release fixes NVIDIA runtime compatibility by switching the Docker base
image from Alpine (musl) to Debian slim (glibc), so `nvidia-smi` injected by
the NVIDIA Container Toolkit is executable inside the container.

It also removes the `update.sh` helper and standardizes update instructions
around Docker Compose (`docker compose pull && docker compose up -d`).

Changes
- Docker runtime base is now Debian slim (glibc) to support `nvidia-smi`.
- Removed `update.sh`; UI/docs now show standard Compose update commands.

See CHANGELOG.md for details.
