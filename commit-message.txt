release: v0.1.19 - PCIe connectivity, nav tweak, compose fix, ~46 Sonar cleanups

Added:
- PCIe connectivity for every detected GPU. The collector queries
  pci.bus_id, pcie.link.gen.{current,max} and pcie.link.width.
  {current,max} from nvidia-smi. The server derives the effective
  unidirectional bandwidth (GB/s) from the PCI-SIG per-lane
  figures (gen 1 to 6).
- Dashboard PCIe card above the processes table: RX / TX
  (full-duplex symmetric figures) + link summary, bus id in the
  header, and a short note that the bandwidth is theoretical.
- System tab "PCIe connectivity" panel per GPU. Big bandwidth
  headline, slot + link rows, and an amber "Degraded link" badge
  with tooltip when the active gen or width is below max.

Changed:
- System tab moved next to Dashboard in the header
  (Dashboard / System / Alerts / Logs / Settings).
- Mock GPU 1 (RTX 3060) now reports PCIe 3.0 x8 so the
  degraded-link badge is visible in dev without a real GPU.

Fixed:
- Docker compose: cap_drop [ALL] alone was too aggressive — the
  image's entrypoint uses `gosu` to drop privileges to `node`
  and needs SETUID, SETGID, CHOWN, FOWNER and DAC_OVERRIDE.
  Without them the container looped on `error: failed switching
  to "node": operation not permitted`. We now drop ALL caps and
  cap_add only those five; no-new-privileges:true stays on.

Refactored (SonarCloud, ~46 issues across the new code):
- Cognitive complexity reductions on alerts.ts PATCH handler,
  alertService.evaluate, exportService.sendWebhook,
  exportService.test, updateService.runCheck, logger.query,
  AboutSettings.renderBody. Each split into helpers.
- Optional chaining x4 (connection, auth middleware,
  exportService x2). NaN -> Number.NaN x2.
  VALID_CONDITIONS / LEVELS turned into Sets with .has().
  Array sort uses String#localeCompare. Two regex
  alternations -> character classes. Three nested template
  literals extracted. Three `void promise()` -> .catch.
- Top-level `await bootstrap()` replaces the swallowed
  `void bootstrap()` so unhandled rejections bubble to the
  runtime (tsconfig already targets ES2022 + ESNext modules).
- themes.ts: makeTheme() helper deduplicates the six theme
  entries flagged on the Duplicated-Lines QG.
- A11y: <div role="group"> swapped for real <fieldset> +
  sr-only <legend> on the System view-mode picker and Logs
  level selector. Renamed the local KV helper to InfoField so
  the React PascalCase rule no longer flags it.
- Misc readability: replace -> replaceAll, typeof window ->
  typeof globalThis.window, flipped a couple of negated
  ternaries.
