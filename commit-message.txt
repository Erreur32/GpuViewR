release: v0.1.26 - InfluxDB test reports the real result

Fixed:
- InfluxDB "Send test" now sends a synthetic line directly to the
  /api/v2/write endpoint and surfaces the broker's actual HTTP
  response (success or the Influx error body for 4xx/5xx). The
  previous version delegated to the periodic push helper, which
  swallows HTTP errors and bails when no samples are collected
  yet — so the test always returned "OK" even with a wrong token,
  missing bucket, or unreachable URL. Adds an 8s AbortController
  timeout with an explicit message.

Note: Prometheus is pull-based; its "test" stays informational
(scrape /metrics from the configured URL).
