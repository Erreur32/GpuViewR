release: v0.3.0 — multi-host + remote agent GPU processes

Major: agents can now publish the list of GPU processes running on
their box. The hub stores per-host snapshots (30 s TTL, no DB roundtrip
because the data has no historical value), `/api/processes?host=<id>`
serves them, and the Dashboard's processes table forwards the
selectedHostId so switching hosts updates the table in place.

Agent side
- `agent/src/collectors/processes.ts` runs `nvidia-smi
  --query-compute-apps` and `nvidia-smi pmon -c 1 -s u` in parallel,
  enriches each row with `/proc/<pid>/cmdline` and delta-based CPU%.
  Self-contained — does NOT import the hub's processCollector — and
  honours HOST_PROC for containerised agents.
- Transport gains a `processes` frame type buffered the same way as
  `sample`, so reconnects replay the most recent snapshot.
- Wired in `agent/src/index.ts` when `features.processes` is on and
  nvidia-smi is available; skipped under MOCK_GPU=1.

Hub side
- New `server/services/agentProcessStore.ts` keeps the per-host
  snapshot in memory with a 30 s staleness check.
- `agentIngestWS.ts` `case 'processes':` is no longer the
  reserved stub — it validates and writes into the store.
- `server/routes/processes.ts` serves agent-supplied data for
  `?host=<non-local>`, maps `gpu_uuid → gpu_index` via metricsBus's
  per-host samples, returns a `reason` field when a snapshot is
  missing or stale so the UI degrades gracefully.

Frontend
- `GpuProcessesTable` accepts `hostId`, fetches with
  `&host=<id>`, and renders a hint when the response includes
  `reason` (agent capability off or snapshot stale).
- Dashboard passes the selected host through.

Dev mock
- New `mockAgentSeeder` registers a synthetic `mock-agent-1` host
  under MOCK_GPU=1, emits fake samples + fake processes every tick
  so the multi-host UI works end-to-end in `dev:mock`.

Fleet UX: GPU cards as gauges
- `GpuMiniTile` renders four System-style arc speedometers (util /
  temp / power / memory) sharing the new `UsageArc` component with
  the System page. 4 cols from sm: upward, 2×2 below.
- View toggle relabelled Détaillé/Compacte → Jauges/Compact and
  reordered (Jauges first) to match Dashboard + System.
- Sparkline below the gauges removed; host-card header sparkline
  stays.

Dashboard + System polish
- View toggle "Bars/Barres" → "Compact" (en + fr) on both pages,
  order already consistent (Jauges first).
- Alerts events table now shows the absolute HH:MM:SS (with date
  prefix on different days) under the relative-time pill; full
  datetime in the hover tooltip.
- System Temperatures hero card no longer applies the dynamic
  radial-gradient background or glow shadow on the outer frame —
  it's a calm surface-alt panel. CPU/GPU sub-frames inside still
  carry the temperature-driven accent.
- System Temperatures heatmap label renamed to "Carte mère" /
  "Motherboard" (was "Carte thermique" / "Thermal map").
- System PCIe Connectivity panel collapsed from a 3-row stack to a
  single wrap row (title + bandwidth + slot + link inline).
  Removes ~40 px of vertical space per GPU card.
