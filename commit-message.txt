release: v0.1.39 - PCIe bandwidth hint moved to info-tooltip

Changed:
- The PCIe "Link bandwidth" inline hint is replaced by a small
  info icon next to the value. Hover or keyboard focus on the
  icon reveals the explanation about ASPM idle downshift in a
  CSS-only tooltip. Hint text itself is unchanged.
- Connectivité PCIe card is denser:
  - py-3 -> py-2 padding,
  - bandwidth label is now inline with the value instead of
    stacked above,
  - section gap reduced (space-y-1.5).
  Net result: ~40% less vertical height per GPU PCIe panel.
- Tooltip uses only --gv-* CSS variables (surface, text, border,
  bg, accent) so it renders correctly on every registered theme
  (Midnight, Graphite, Oceanic, light variants) without any
  hard-coded colour.
