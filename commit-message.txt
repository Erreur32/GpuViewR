release: v0.9.4 close /api/auth/register after the first admin

- Security: POST /api/auth/register stayed open to anyone with
  network access even after the first admin existed. Registration
  now stays open only for the zero-user bootstrap case; only an
  authenticated admin can create further accounts afterward.
- Fixes a TOCTOU race where two concurrent bootstrap requests could
  both get promoted to admin.
