release: v0.1.16 - fan curve + stats, Royal default palette, alert presets

- Fan speed promoted to a 5th chart series (% scale) with its own
  legend chip, threshold line, color picker and a Stats tile so the
  fan_speed metric the collector already stores in SQLite is finally
  exposed in the UI.
- Royal palette is now seeded on first launch via a one-shot
  chart_palette_initialized flag in localStorage, leaving any
  existing custom colors untouched on upgrade.
- New /alerts/presets endpoints + Presets modal seed the 9 classic
  GPU alerts (temp critical/high, VRAM saturated/high, power high,
  sustained 100% util, fan runaway/stalled, idle anomaly). Rules are
  installed disabled so the user reviews thresholds before arming.
