release: v0.1.9 - About tab, processes, Live filter, security hardening

Settings
- About tab with logo, version, features, GitHub links, MIT and
  embedded changelog viewer (GET /api/info/changelog).
- Tabbed Settings (General / Exports / Database / Updates / About).
- Chart thresholds card (toggle + per-metric value + clear + reset).
- Update banner is now permanently dismissible (toggle in About tab).

Chart
- Cursor tooltip with date/time and visible curve values.
- Gradient area fills (util, temp, pow).
- Live (50s) range replacing 1m / 2m, with auto-migration.
- X-axis honors 24h / 12h preference.
- gpuStore.ingest is now immutable so live ticks always render.

GPU
- Per-process GPU table (PID / process / VRAM) polling
  /api/processes[?gpu=<i>], cached 1.5s server-side.

Layout
- max-w-7xl -> max-w-[1600px] on header / main / Settings.

Security
- Rate limiting on /api, /api/auth and /metrics (express-rate-limit),
  trust proxy = 1.
- Prometheus label escaping (backslash, quote, newline).
- MQTT clientId via crypto.randomBytes.
- HTTPS placeholder for the InfluxDB URL field.
- Paired onKeyDown for the chart color picker label.
- SECURITY.md with disclosure flow.
- Dockerfile: apt-get upgrade in both stages, FROM pinned to digest.
- CI actions pinned to commit SHAs, release.yml minimal token perms.
