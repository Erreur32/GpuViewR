feat(agent): GPU processes from remote agents + Fleet UX gauges

Multi-host: GPU processes from agents
- New `agent/src/collectors/processes.ts` — same nvidia-smi
  query-compute-apps + pmon path as the hub's processCollector,
  enriched with /proc/<pid>/cmdline + delta-based CPU%. Self-
  contained, honours HOST_PROC for containerised agents.
- Agent transport gains a `processes` frame type (ts_epoch +
  processes[]) buffered the same way as SampleFrame so reconnects
  replay it.
- Hub `agentIngestWS.ts` `case 'processes':` is no longer the
  reserved stub — it writes into a new per-host `agentProcessStore`
  with a 30 s TTL (snapshots have no historical value).
- `server/routes/processes.ts` serves real data for `?host=<non-local>`:
  reads the store, maps gpu_uuid → gpu_index using metricsBus's
  per-host latest samples, applies the optional ?gpu= filter, and
  returns a `reason` field when the snapshot is missing/stale so
  the UI can degrade gracefully.
- Frontend: `GpuProcessesTable` now takes `hostId`, forwards it to
  `/api/processes?host=<id>&gpu=<idx>`, and surfaces the `reason`
  string as an empty-state hint when an agent's capability is off.
- Dev-only mock: `mockAgentSeeder` registers a synthetic
  `mock-agent-1` host under MOCK_GPU=1, emits fake GPU samples
  with distinct UUIDs and pushes fake processes every tick so
  `dev:mock` exercises the multi-host path without a real agent.

Fleet UX: GPU cards as gauges
- `GpuMiniTile` renders four System-style arc speedometers (util /
  temp / power / memory) instead of the mini-bars. Same 5-band
  heat gradient, same glow filter, same `gauge-pulse` ≥90% danger
  animation as `SystemPage`'s UsageArc.
- Single-row layout from sm: upward, 2×2 on very narrow phones.
- Fleet view toggle relabelled Détaillé/Compacte → Jauges/Compact
  and reordered (Jauges first, Compact second) to match
  Dashboard/System. Sparkline below the gauges removed; the
  host-card header sparkline (avg util) stays.

Dashboard + System polish
- View toggle "Bars/Barres" relabelled to "Compact" (en + fr) on
  Dashboard and System; both already render Jauges-first so order
  is consistent across the three pages.
- Alerts events table: each event now shows the absolute HH:MM:SS
  (with date prefix on different days) below the relative-time
  pill; full datetime is in a hover tooltip.
- System Temperatures hero card no longer applies the temperature-
  driven radial-gradient background or glow shadow on the outer
  frame — it's a calm surface-alt panel. The CPU/GPU sub-frames
  inside still carry the accent.
- System Temperatures heatmap label renamed to "Carte mère" /
  "Motherboard" (was "Carte thermique" / "Thermal map") since the
  strip is built from motherboard hwmon sensors.
- System PCIe Connectivity panel collapsed from a 3-row stack
  (header + bandwidth + Grid<slot, link>) to a single wrap row
  with title + bandwidth + slot + link inline. Removes ~40 px of
  vertical space per GPU card. Dead `Grid` and `InfoField`
  helpers deleted.
