release: v0.9.17 GPU process list on Windows agents

- Added: Windows agents report the GPU process list from the per-process
  PDH counters (GPU %, dedicated VRAM, type, CPU %, command line), for
  NVIDIA, AMD and Intel. With nvidia-smi, processes are attached to the
  right card by matching pids against nvidia-smi -q -d PIDS.
- Fixed: PDH GPU utilization (AMD/Intel on Windows) likely stuck at 0 %,
  the engine counter regex missed the pid_<pid>_ prefix.
