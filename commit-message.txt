release: v0.8.4 — rotate-token modal shows full install one-liner per platform

User feedback after the v0.8.2 chicken-and-egg Windows-update saga:
when you regenerate a token, what the operator actually needs is
the COMMAND to re-run on the remote host, not just the raw token
string. The old modal handed back the raw token and left it to the
user to remember the install one-liner format or look it up in
docs.

v0.8.4 brings the rotate-token modal in line with the Add-host
modal:
- After a successful rotate, render a Linux-bash / Docker /
  Windows-PowerShell toggle.
- Each option pre-filled with the new `host_id.secret` composite.
- Default selection follows the host's reported install_mode, so
  the user sees their own platform's command first
  (`install_mode='windows'` → Windows tab pre-selected, etc.).
- Raw token still available behind a <details> block for
  Ansible / custom installers.

Modal width bumped to max-w-2xl to fit the install command's
wider mono-spaced layout.

Files
- src/components/settings/HostsSettingsTab.tsx:
    - RotateInstallMode type + defaultRotateModeFor() helper.
    - RotateTokenModal rebuilt around the same cmdByMode /
      labelKeyByMode lookup tables EnrollHostModal uses — the
      two modals are now shape-aligned, easier to maintain.
- src/i18n/locales/{en,fr}.json:
    - hosts.rotate_done_hint rewritten ("copy install command +
      re-run on host").
    - New key hosts.rotate_show_raw_token for the collapsible
      raw-token block.

Verified: tsc 0 errors, vite build green.

Upgrade
- Hub: docker compose pull && up -d --force-recreate.
- Effect immediate on next token rotation.
